# ASTRA Assistant 4.1.0 — Agent Team and Second Brain

This release adds an on-device orchestrator with eight precise specialist roles: coordination, study, research, engineering, aerospace, gaming, content creation and precision review.

- Persistent DPAPI-encrypted work queue with planning, specialist handoffs, review, final synthesis, cancellation, recurring work and checkpoint recovery.
- Separate background worker that continues after the main window closes, with optional Windows login startup.
- Shared memory, lexical and local embedding-based note retrieval, selected-project reading, optional cited public web research and deterministic ASTRA numerical simulations.
- Interactive local knowledge graph connecting notes, concepts, documents, projects, tasks, evidence, agents and skills.
- Per-note encrypted storage with automatic legacy migration; removes the previous 1,000-note and aggregate notebook-size limits.
- Configurable local GGUF model, context, generation length and CPU threads. No daily ASTRA job quota or required paid inference service.
- Conversation delegation, complete evidence ledgers and Markdown report export.
- One ASTRA Assistant identity across every profile; Second Brain is its internal shared memory.
- Local voice recording/transcription, spoken deliverables, WAV export and real local pixel vision through an included SmolVLM model/projector.
- Reusable JSON/Markdown skills with creation, editing, import/export and per-agent assignments.
- Gaming Session Strategist, controlled A/B experiment worksheets and shared checkpoints.
- Creator Launch Studio for multi-format content packs, accessibility reviews, saved briefs and handoff exports.

The worker runs one local generation at a time and requires an awake PC and an active Windows session. The included small CPU model favors accessibility over advanced reasoning quality; larger compatible local models can be selected. PDF retrieval remains lexical. Specialist reviews and citation-ID checks do not establish scientific validity. Existing script and project-edit review workflows remain available separately.

Download the named Windows ZIP or Setup executable from this release. Keep the full application folder together. User data and QA profiles are excluded. Read **AGENT-BRAIN-GUIDE.md** for the precise tool scope, compute settings, migration and workflow.
