# ASTRA ISO Builder v2 — local use only

This tool **does not create a new Microsoft-licensed OS or Windows activation key** and does not include Windows files in the ASTRA repository. The user must provide legitimately acquired Windows installation media. The result is **not eligible for public distribution without applicable rights to Windows content**.

Requirements: Windows 11 x64, Windows ADK **Deployment Tools / oscdimg**, mounted/extracted official Windows 11 installation media, enough free disk space for a temporary copy and output ISO, a published ASTRA application folder containing `Astra.Desktop.exe`.

```powershell
# Plan mode: validates required paths, no filesystem writes by ASTRA ISO Builder.
.\scripts\New-AstraIso.ps1 -SourceMediaDirectory 'D:\' -AstraDistributionDirectory '.\dist\AstraOS' -OutputIso 'C:\temp\ASTRA-private.iso'

# Explicit opt-in after reviewing the plan and ensuring sufficient disk space.
.\scripts\New-AstraIso.ps1 -SourceMediaDirectory 'D:\' -AstraDistributionDirectory '.\dist\AstraOS' -OutputIso 'C:\temp\ASTRA-private.iso' -Build
```

The builder copies the Windows media and adds an `ASTRA-OS` folder plus a README. ASTRA does not patch protected Windows binaries, does not alter startup/WinPE or automatically install software. The ISO has UEFI+BIOS boot image metadata provided by the source media and is generated by Microsoft `oscdimg`.

**Requires real Windows tests:** path edge cases, FAT32/UEFI media constraints, oscdimg version compatibility, final ISO mount/extraction and boot of both Windows Setup and manual ASTRA launch in a virtual machine. No ISO was created in the Linux authoring environment.
