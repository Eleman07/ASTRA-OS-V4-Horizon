# V2 design language — ASTRA Horizon

- Base canvas `#070C17`, navigation surface `#0B1426`, card surface `#101D33`.
- Primary accent is cold electric blue `#91C6FF`; secondary green `#68E8B6`. Hero uses a layered blue/navy gradient with orbital mark.
- Type: Segoe UI Variable for brand and system UI, prominent 27–30pt headings, small capitalized eyebrow text for context.
- Shared control styles use 10–14px rounded corners and visual structure rather than GPU-expensive blur everywhere.
- Primary areas: Dashboard, Profiles, App Hub, Performance, Security, Second Brain, Plugin SDK, 3D, ISO Builder.
- User controls are explicit; no invisible AI listening, polling or resident overlay. Eco defaults on and 3D remains off until user activation.
- Accessibility backlog: high-contrast OS theme, scalable panel/window breakpoints, localized EN/IT resources, full keyboard focus order, screen reader semantics, verified reduce-motion behavior and profiling.
