# ASTRA OS Horizon 4.4.0 — Conversation OS

ASTRA Assistant is now one themed page with an embedded persistent conversation, central knowledge graph, side controls and timestamped live activity terminal. Send an objective from the conversation: automatic routing selects relevant specialists and their assigned methods for complex deliverables, while quick requests can stay direct. Results return to the same conversation. Users can override agents, skills, input type, provider, optional web research and deterministic calculations.

Includes saved conversation access, project/script review, skills creation/import/export, full job reports, graph-node focus-to-chat and durable background delivery. Completed replies are stored in their linked encrypted conversation even if the main window closes; idempotent delivery avoids duplicate responses after retries. Source material and returned output remain complete subject to upstream context/output limits.

The graph loads automatically, with initial display/pixel-density/animation budgets based on RAM, CPU, eco and reduced-motion preferences. Graph previews are lightweight and explicitly labeled; focus-to-chat loads the full original node. Working-state animations highlight active agents and stop when idle. The terminal records observed events and waits, not hidden model reasoning.

Desktop 3D starts automatically when opened. Its central star has a flowing plasma-wave surface in two/three theme-derived colors, a luminous corona and animated rings. Graph and desktop native renderers are closed/removed on page changes or window deactivation and recreated on return. The OS may retain shared WebView2 caches; this is not a claim of instant zero RAM. Conversations and authorized background jobs remain available.

Validation includes 184 existing multi-agent checks, 21 conversation/render-policy/durable-delivery checks, 63 static tests and 16 native UI/renderer checks. The native checks include automatic load/unload/recreation, activity animation, full >110,000-character focus-to-chat content and actual WebGL star geometry. A genuine Codex request completed coordinated handoffs and returned sourced flashcards to the same conversation. The earlier 56-test CubeSat result is historical, not a new benchmark of this UI release. See `docs/UNIFIED-4.4.0-VERIFICATION.md` and the installer verification asset for scope.

Requires your own Codex-enabled ChatGPT account and official CLI for the recommended provider, or your own OpenRouter key for explicitly selected eligible free routes. Plan/provider quotas and availability remain; there is no paid fallback. Whisper small/tiny speech uses CPU in Codex mode. No personal vault, account, credential, private job or generated personal project is bundled. Setup is unsigned and does not represent independent security or engineering certification.
