# ASTRA OS Horizon 4.3.0 — Codex Second Brain

This release unifies ASTRA Assistant, Obsidian memory and a visual knowledge graph with nine specialist roles and 39 reusable skills. The interface presents workflows, source material, model/account selection, progress and concrete deliverables together.

The recommended workflow requires the official Codex CLI and your own ChatGPT account with Codex access. ASTRA uses its native sign-in rather than storing a fixed account. Select a model/effort available to your plan. Alternatively, explicitly choose OpenRouter free models with your own API key. Zero-price enforcement remains enabled; both providers retain their usage/context/availability limits. There is no implicit paid or local text-model fallback.

Includes CPU Whisper small/tiny speech input, Windows OCR and speech output, Codex image interpretation, long-input/output preservation, role-assigned methods, skill creation/import/export, encrypted jobs/checkpoints, worker recovery and procedural lessons. Generated source files are exported for review rather than silently executed.

Observed checks: 184 multi-agent Core checks, 63 static regressions and 10 native UI checks. A genuine selected-Codex-model CubeSat project completed five handoffs; its unchanged generated sources passed 56 pytest cases plus independent CSV energy/accuracy/convergence checks. These are scoped educational numerical results, not flight validation or guaranteed performance on all tasks/models.

The 4.3 EXE passed 18 isolated installation/uninstallation checks: all 948 installed payload files matched hashes, version/shortcuts/uninstall registration were correct, nested junctions were rejected and unknown user files survived uninstall. The installer was tested without running the Microsoft prerequisites or a live model during installation QA. It is unsigned and does not represent independent security certification.

Download the named Setup EXE or portable ZIP, plus its matching SHA-256 asset. Personal vaults, private conversations, credentials, browser profiles and generated private outputs are excluded. The full application source is now in the repository, without local model weights or secrets. See README and `docs/CODEX-4.3.0-VERIFICATION.md` for setup, capabilities and limits.
