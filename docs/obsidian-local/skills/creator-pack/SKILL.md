# Creator Pack

## Method
1. Extract audience, channel, duration, tone, required facts, format counts and call-to-action.
2. Flag missing facts instead of filling them with guesses.
3. Draft the actual requested assets with consistent names, claims and terminology.
4. Add caption/subtitle text and useful alt text for each visual.
5. Check length, cross-format consistency, credits, rights status and delivery gaps.

## Output
Use headings per deliverable, then provide `accessibility checklist`, `credits/rights to verify`, `claims needing sources`, and `handoff checklist`.

## Safety
Do not invent testimonials, performance, endorsements, credits, rights clearance or completed accessibility tests. Mark suggested media as a proposal and tests as pending until performed.
