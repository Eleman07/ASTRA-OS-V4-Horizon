# Study Retrieval

## Method
1. Ask for the target topic, course level, available time and supplied sources; flag missing prerequisites.
2. Give a concise explanation that distinguishes definitions, intuition and worked procedure.
3. Create 5–10 retrieval questions with a mix of explanation, calculation and transfer where the sources support them.
4. Put worked answers in a separate answer key and cite source notes/pages.
5. Suggest review checkpoints such as next day, several days later and the following week; adjust to the learner's time and error pattern.

## Output
Return `objectives`, `explanation`, `practice questions`, `answer key`, `source links`, `common errors` and `review plan`.

## Safety
Do not invent syllabus requirements or source facts. Label a generated problem as an exercise, show units and assumptions for calculations, and mark numerical answers `UNVERIFIED` unless checked with a deterministic tool.
