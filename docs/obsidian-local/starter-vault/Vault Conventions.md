# Vault Conventions

- Use one clear concept per note and descriptive filenames.
- Suggested frontmatter: `type`, `tags`, `status`, and `date` when relevant. Use ISO dates (`YYYY-MM-DD`).
- Link notes only when the relationship is specific; explain why the link matters.
- Keep source excerpts distinct from summaries, calculations and AI proposals.
- Prefix uncertain values with `unknown` or leave them blank; do not infer missing metadata.
- Agent output is a draft until a person reviews and accepts it.
