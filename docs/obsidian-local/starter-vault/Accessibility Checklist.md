# Accessibility Checklist

- [ ] Provide useful alt text for meaningful images.
- [ ] Check captions or subtitles against the final audio.
- [ ] Use readable contrast, text size and plain language.
- [ ] Avoid conveying status by color alone.
- [ ] Record keyboard, remapping, difficulty and sensory options relevant to the task.
- [ ] Mark every check `verified`, `not applicable` or `not checked` with evidence.
