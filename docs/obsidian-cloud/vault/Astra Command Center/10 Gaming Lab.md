# Gaming Lab

Choose a measurable question: performance configuration, practice efficiency, strategy consistency, accessibility or a campaign knowledge base. Record the actual game version and conditions before comparing runs.

Use [[Astra Command Center/90 Templates/Gaming Experiment|Gaming Experiment]] for an A/B test. Use [[Astra Command Center/11 Experiment Scoreboard|Experiment Scoreboard]] for comparisons across repeatable runs.

## Useful agent outputs

- Explain a strategy from supplied replay timestamps, patch notes and observed decisions.
- Build an accessible practice progression with a clear success criterion.
- Compare settings using actual frame-time/FPS/latency logs when those files exist.
- Maintain a spoiler-aware build or quest database with versioned sources.
- Turn a session transcript into mistakes, hypotheses and one next practice drill.

Do not infer FPS, frame time, network latency or causal improvement from CPU/GPU utilization alone. Mark unmeasured metrics as missing. Separate game-mechanics claims from player observations and patch-sensitive advice.
