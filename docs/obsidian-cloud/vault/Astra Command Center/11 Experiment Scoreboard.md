# Experiment Scoreboard

One controlled change per comparison. Keep repeated samples, warm-up, run duration and the condition order. A single better run is not a demonstrated causal effect.

## General experiment questions

- What changed, and what was held constant?
- Which metric was selected before the run?
- What outcome would falsify the hypothesis?
- Were failed runs excluded, and why?
- Is the observed difference larger than measurement noise?

This board can also track a study method, creator content experiment or technical benchmark. Use the same evidence discipline across areas.
