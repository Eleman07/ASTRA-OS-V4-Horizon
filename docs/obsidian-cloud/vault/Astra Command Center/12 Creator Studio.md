# Creator Studio

Start with the audience's need and the result the content should produce. Define platform, format, tone, accessibility and available source material before asking for a script.

Use [[Astra Command Center/90 Templates/Creator Brief|Creator Brief]] for a new asset and [[Astra Command Center/90 Templates/Storyboard|Storyboard]] to map narration to visuals. Track delivery in [[Astra Command Center/13 Content Pipeline|Content Pipeline]].

## Useful outputs

- A long technical article derived from source-linked research notes.
- A video script with claim evidence, shot list, captions and references.
- Several platform-specific versions that preserve the underlying factual meaning.
- An accessibility pass for alt text, subtitle readability and visual explanation.
- A post-publication experiment comparing the intended audience response with actual measurements.

Keep evidence, creative invention and illustrative analogy clearly labeled. Record permissions and licenses for media; a model cannot certify rights from a filename. Review scientific claims against [[Astra Command Center/07 Evidence Ledger|Evidence Ledger]].
