## Examples to investigate

- Use a technical verification matrix to make a creator delivery checklist measurable.
- Use controlled gaming A/B practice to test a study method against delayed retrieval scores.
- Turn a reviewed aerospace model into a visual lesson, while labeling simplifications.
- Reuse a research evidence matrix to compare patch-sensitive gaming strategies.

Ask the Curator to propose a small number of descriptive links and explain why each helps retrieval. Accept useful links after review; adding many unexplained edges does not create a reliable knowledge graph.
