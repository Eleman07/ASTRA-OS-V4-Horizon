## Useful prompt

> Use the selected syllabus and source notes. Explain this topic at my current level, list prerequisite gaps, then create 12 atomic flashcards, a linked concept map, 5 progressively harder exercises and a timed mock exam. Cite source locations, keep solutions in a separate section and provide a marking rubric. Verify every numeric solution with a deterministic method or mark it UNVERIFIED.
