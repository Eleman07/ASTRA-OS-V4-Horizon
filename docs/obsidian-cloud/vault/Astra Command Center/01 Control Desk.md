## Dispatch contract

Create a [[Astra Command Center/90 Templates/Task Contract|Task Contract]] before a large task. Include the selected STEM area, input files and expected output format. Ask for missing assumptions to be explicit and for unresolved calculations to remain `UNVERIFIED`.

## Decision replay

When a recommendation affects a project or schedule, record a [[Astra Command Center/90 Templates/Decision Record|Decision Record]]. Revisit it when a stated assumption changes, rather than rewriting the historical rationale.

## Useful core workflows

- Turn a meeting transcript into decisions, owners, deadlines and open questions; preserve timestamps.
- Compare alternatives against your actual constraints and record why one was selected.
- Produce a checklist whose completion can be demonstrated by files, measurements or review.
- Make a weekly synthesis linking accepted outputs and outstanding verification work.

Review unresolved claims in [[Astra Command Center/16 Verification Debt|Verification Debt]] before reusing an AI draft.
