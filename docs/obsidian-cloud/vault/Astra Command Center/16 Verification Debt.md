# Verification Debt

This is a queue of claims, tests and assumptions that must be checked before reuse. Keep the original draft intact; update the verification state with new evidence.

| VD-001 |  |  |  |  |  | open |

Priority is driven by consequence and downstream dependencies. Close an item only when the required evidence is linked; a model's confidence or a second model's agreement is not enough.

## Useful checks

- Recompute an aerospace number with explicit units and saved inputs.
- Open the claimed paper page and compare the actual wording.
- Re-run a simulation with the recorded environment and seed.
- Confirm that an OCR equation has the correct signs and indices.
- Verify a recovery test and a usable rollback artifact.
