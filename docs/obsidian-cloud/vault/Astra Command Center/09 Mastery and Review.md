## Error-to-action loop

1. Write the attempted answer before opening a solution.
2. Score with the rubric and keep the actual mistake.
3. Identify the smallest missing prerequisite or incorrect step.
4. Generate a varied exercise that tests the same competency.
5. Review after a delay and record whether retrieval improved.

Flashcard intervals are suggestions until your chosen review system records an actual review. The [[Astra Command Center/90 Templates/Flashcard|Flashcard template]] supplies a log; it does not schedule reminders by itself.
