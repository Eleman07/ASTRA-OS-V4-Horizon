# Evidence Ledger

Evidence IDs connect claims to original sources and allow a reviewer to check them. Keep quotations separate from paraphrases; cite exact pages, sections, timestamps, file lines or dataset rows.

## Claim states

- **Source verified:** the source was opened and actually supports the wording.
- **Computed:** reproducible code or a deterministic calculation produced the value.
- **Measured:** a named test produced an actual observation with known conditions.
- **Inference:** a reasoned interpretation, with supporting and contrary evidence.
- **UNVERIFIED:** source, calculation or measurement is missing.

Queue unverified or stale items in [[Astra Command Center/16 Verification Debt|Verification Debt]]. Use [[Astra Command Center/90 Templates/Evidence Note|Evidence Note]] for a full source record.
