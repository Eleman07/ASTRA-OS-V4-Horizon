# ASTRA Command Center

Capture a question, define the output you need, then let specialist agents work against named evidence. This workspace connects each result to a source, a decision and a verification step.

## Choose your workspace

| Workspace | Start here | Typical deliverable |
| --- | --- | --- |
| Technical / aerospace | [[Astra Command Center/03 Aerospace Studio|Aerospace Studio]] | Model, requirements, trade study, test and risk evidence |
| STEM research | [[Astra Command Center/06 Research Observatory|Research Observatory]] | Evidence-backed synthesis and reproducibility package |
| Study | [[Astra Command Center/08 Study Lab|Study Lab]] | Explanation, flashcards, exercises, mind map and mock exam |
| Gaming | [[Astra Command Center/10 Gaming Lab|Gaming Lab]] | Measured experiment and focused practice plan |
| Creator | [[Astra Command Center/12 Creator Studio|Creator Studio]] | Brief, storyboard, source/rights checks and delivery plan |
| Everyday work | [[Astra Command Center/01 Control Desk|Control Desk]] | Clear next actions and reviewed outputs |
| System improvement | [[Astra Command Center/15 Evolution and Recovery|Evolution and Recovery]] | Tested proposal, recovery record and rollback plan |

## Daily launch

1. Triage [[Astra Command Center/02 Inbox|Inbox]] into a note, task or discard decision.
2. Fill a [[Astra Command Center/90 Templates/Task Contract|Task Contract]] for the most valuable work.
3. Select the agents and method in [[Astra Command Center/17 Agent Playbook|Agent Playbook]].
4. Reuse evidence through [[Astra Command Center/07 Evidence Ledger|Evidence Ledger]] and track uncertainty in [[Astra Command Center/16 Verification Debt|Verification Debt]].
5. Close the loop in [[Astra Command Center/18 Weekly Review|Weekly Review]].

For recordings and screenshots, start with [[Astra Command Center/14 Multimodal Capture|Multimodal Capture]]. Use [[Astra Command Center/19 Connections and Idea Transfer|Connections and Idea Transfer]] to turn reviewed knowledge into useful connections across profiles.
