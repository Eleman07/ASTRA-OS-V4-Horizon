# Trade Studies and Risks

## Trade-study discipline

Compare feasible alternatives against the same mission, dataset and assumptions. Separate hard constraints from weighted preferences. Record the score's measurement method, normalization, weight and evidence. Perform sensitivity analysis before treating a narrow winner as decisive.

Start a [[Astra Command Center/90 Templates/Trade Study|Trade Study]] and record the accepted choice in a [[Astra Command Center/90 Templates/Decision Record|Decision Record]].
