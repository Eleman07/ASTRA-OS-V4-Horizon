# Plugin locali ASTRA

Operazioni dichiarative senza shell, rete, filesystem o codice importato.

| Plugin | Categoria | Funzione |
|---|---|---|
| Reading Compass | Studio | Stima il tempo di lettura a 220 parole/minuto. |
| Keyword Lens | Studio | Trova le parole ricorrenti, senza inviare il testo a un modello. |
| Text Detox | Testi | Normalizza spazi, tabulazioni e righe vuote. |
| Duplicate Radar | Dati | Rimuove le righe duplicate conservando l'ordine. |
| Line Sorter | Dati | Ordina le righe in modo deterministico. |
| Slug Studio | Codice | Crea uno slug da un titolo, con normalizzazione Unicode. |
| Action Checklist | Organizzazione | Trasforma una lista in una checklist Markdown. |
| Quote Builder | Testi | Prepara citazioni Markdown multilinea. |
| Readable Lines | Testi | Ridistribuisce il testo su righe da circa 72 caratteri. |
| JSON Lens | Codice | Valida e formatta JSON con profondità limitata. |
| JSON Compact | Codice | Valida JSON e rimuove gli spazi superflui. |
| Base64 Encoder | Codice | Codifica testo UTF-8 in Base64; non è cifratura. |
| Base64 Decoder | Codice | Decodifica Base64 UTF-8 con validazione degli errori. |
| Fingerprint SHA-256 | Codice | Calcola l'impronta del testo inserito. |
| URL Encoder | Codice | Codifica una componente URL, senza aprire collegamenti. |
| URL Decoder | Codice | Decodifica una componente URL come testo. |
| UUID Forge | Codice | Genera un identificatore UUID v4 locale. |
| Measurement Notebook | STEM | N, media, mediana, deviazione standard e incertezza standard della media. |
| Distribution Sketch | STEM | Costruisce un istogramma testuale dei campioni numerici. |
| Z-Score Lab | STEM | Standardizza i campioni usando la deviazione standard della popolazione. |
| Outlier Detective | STEM | Segnala valori oltre 1,5 IQR; un'indicazione statistica, non una prova di errore. |
| Trend Fit | STEM | Regressione lineare ai minimi quadrati su coppie JSON [x,y]. |
| Correlation Compass | STEM | Correlazione di Pearson su coppie JSON [x,y]; non implica causalità. |
| Signal Smoother | STEM | Media mobile con finestra esplicita, senza inventare campioni iniziali. |
| Table Publisher | Dati | Converte CSV con intestazione in una tabella Markdown. |
| CSV Bridge | Dati | Converte CSV numerico/testuale in un array JSON di oggetti. |
| Vector Workbench | STEM | Prodotto scalare, vettoriale e norme di due vettori 3D. |
| Matrix Microscope | STEM | Determinante, traccia e inversa di una matrice 2×2. |
| Root Explorer | STEM | Risolve ax²+bx+c=0, includendo le radici complesse. |
| Unit Bridge | STEM | Conversioni dimensionali SI, temperatura, angoli e velocità. |
| Complex Plane Kit | STEM | Somma, prodotto e moduli di due numeri complessi [re,im]. |
| Active Recall Cards | Studio | Trasforma righe domanda | risposta in schede ripassabili. |
| Feynman Canvas | Studio | Prepara una traccia di spiegazione da completare sul tema indicato. |
| Lab Report Canvas | Studio | Crea la struttura di un rapporto scientifico, senza generare risultati. |
| Spaced Review Planner | Organizzazione | Calcola date di ripasso a +1, +3, +7, +14 e +30 giorni. |
| Focus Blocks | Organizzazione | Divide minuti di studio in blocchi da 25 minuti e pause da 5. |
| Contrast Inspector | Creator | Calcola il contrasto WCAG di due colori #RRGGBB. |
| Tint Laboratory | Creator | Genera cinque tonalità chiare/scure da un colore esadecimale. |
